## 这个站点

站点是纯静态的：内容用 Markdown 写，[Zola](https://www.getzola.org/) 在构建时渲染成 HTML，托管在 GitHub Pages 上。

没有数据库、没有后端服务、没有 Node——一次 `zola build` 就是全部。想了解细节可以看 [为什么这个站点是静态的](@/blog/hello-zola.md)。
